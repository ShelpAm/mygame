# The Sunset Straits — Design Philosophy

## 世界观

青铜时代晚期的地中海东岸。乌加里特刚刚陷落，海上民族在沿海劫掠，埃及势力衰退，旧的秩序在崩塌，新的世界尚未成形。

玩家是一个在混乱中求生的普通人。没有天命，没有预言。你不是英雄——你只是恰好还活着。

## 核心理念

### 1. 知识即资本

在这个世界里，**你知道什么比你有多少钱更重要**。

- 哪条商路还安全、哪个城邦在招兵买马、谁和谁结盟了——这些信息能救命，也能换钱。
- NPC 之间会分享知识，谣言会传播，你告诉一个人的消息可能传到不该知道的人耳中。
- 你可以选择分享情报来获得信任，也可以选择沉默以保守秘密。

### 2. 真实的 NPC 关系

NPC 不是任务发布机。每个 NPC 有自己的：

- **身份**：商人、难民、祭司、士兵、水手……
- **性格**：友好、多疑、傲慢、胆小……
- **对你的态度**：由 trust（信任值）驱动，从敌视到信任，言行完全不同

对话不是选"接受/拒绝任务"，而是自然的交流——你可以问候、询问、送礼、威胁、甚至攻击。NPC 会根据你的行为和 reputation 做出真实反应。

### 3. 沉浸于一个活的世界

- 世界不是围绕玩家运转的。NPC 之间有他们自己的关系网络，事件在你看不到的地方发生。
- 城邦之间有外交、贸易、战争。你的行为可以影响这些关系，也可能被卷入其中。
- 生存是持续的挑战：食物、水、体力、伤势。你不是无敌的。

### 4. 扁平且轻量

- 没有等级系统、没有经验值。强弱不由数字决定，而由你的装备、知识和策略决定。
- 战斗是危险的，应该尽可能避免。
- UI 简洁、信息密度高。不把菜单当游戏内容。

### 5. 文化真实感

- 以中文为主要语言，英文为翻译。
- 名字、地名、物品名称尽量还原青铜时代地中海的文化背景。
- 不是"剑与魔法"的中世纪奇幻，而是基于历史资料的古代世界。

## 设计原则

> 每一行代码都是为了回答一个问题：**这个世界是什么样子，你在其中是谁？**
